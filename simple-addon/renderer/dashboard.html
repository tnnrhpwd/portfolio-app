            New automation trigger
            
      
            Automatically start a goal on a schedule, when a file lands in a folder, or on a hotkey. Goals are created from the Agent tab or the web app.
            

      
            
        
            
          
            When to fire
            
          
            Pick the trigger kind, then fill in its details below.
            
        
            
        
            
          
        
            
      
            

      
            
        
            
          
            Cron expression
            
          
            Five fields: minute hour day-of-month month day-of-week. "0 9 * * *" = every day at 9:00 AM.
            
        
            
        
            
          
        
            
      
            

      
            
        
            
          
            Folder + file pattern
            
          
            Fire when a matching file is created or changed in this folder. Use * for "any file". Skills can read the file via ${param.file} / ${param.filename} / ${param.eventType}.
            
        
            
        
            
          
          
        
            
      
            

      
            
        
            
          
            Global hotkey
            
          
            e.g. CommandOrControl+Alt+1. Must include at least one non-shift modifier.
            
        
            
        
            
          
        
            
      
            

      
            
        
            
          
            Run what
            
          
            A goal (agent-planned) or a recorded skill (macro). Skills run locally, even signed out.
            
        
            
        
            
          
        
            
      
            

      
            
        
            
          
            Goal
            
          
            The goal that starts when this trigger fires.
            
        
            
        
            
          
          
        
            
      
            

      
            
        
            
          
            Recorded skill
            
          
            The skill (macro) to run when this trigger fires.

            Dry-Run Mode
            
          
            Tools simulate execution and never touch the system. Useful when testing a new goal.
            
        
            
        
      
            
      
            
        
            
          
            Network Binding
            
          
            
            Loopback = only this PC can reach the addon (safest). LAN = phones/tablets on the same WiFi can connect via the IP shown in /api/network. Requires addon restart.
          
            
        
            
        
      
            
      
            
        
            
          
            Emergency Kill Switch
            
          
            Immediately halts the agent and refuses every tool call until disabled.
            
        
            
        
      
            
    
            

    
            
      
            Sensitive Data Consents
            
      
            
        Synced to your account — granting or revoking here applies on every device/addon install signed into the same account.
      
            
      
            
        
            
          
            Keyboard Capture While Recording
            
          
            Lets the macro recorder capture keystrokes (e.g. typed text) so recorded macros can replay them. Required to record any macro that involves typing.
            
          
            
        
            
        
      
            
      
            
        
            
          
            Cloud Vision (screenshot analysis)

            Shell Command Filters
            
      
            
        
            Allow-list patterns (regex, one per line)
            
        
            If a shell command matches any of these, it auto-approves without prompting.
            
        
      
            
      
            
        
            Deny-list patterns (regex, one per line)
            
        
            Commands matching ANY of these are refused unconditionally, even with approval.
